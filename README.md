Welcome to my central software repository. This space serves as a portfolio of my development journey, ranging from structured command-line utilities to advanced file-persisted data analytics engines.

Below is an interactive map of the projects housed in this repository. Click on any project title to jump directly into its folder to view its code and dedicated documentation.
