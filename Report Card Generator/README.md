# Report Card Generator 📊

An interactive Python command-line application that automates the creation of student report cards. The program collects student information, enforces strict data validation for marks, and calculates performance statistics.

## 🚀 Features

* **Smart Data Validation:** Uses continuous input loops to ensure users can only enter valid grades (8, 9, or 10), valid sections (A, B, or C), and realistic exam marks (0 to 100).
* **Automated Grade Calculations:** Automatically computes the student's total score, exact grade point average, and isolates their highest-scoring subject.
* **Dynamic Feedback Logic:** Evaluates the student's average to instantly assign a final letter grade (`A`, `B`, `C`, or `Fail`) alongside a tailored performance comment.
* **Batch Processing Loop:** Features a built-in prompt at the end of the script allowing users to generate multiple report cards consecutively without needing to restart the program.

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Interface:** Command Line / Terminal
