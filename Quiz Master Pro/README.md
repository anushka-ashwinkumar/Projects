# Quiz Master Pro 🧙‍♂️✨

An interactive, terminal-based trivia application built in Python. This project tests the user's knowledge on Harry Potter lore using a structured, function-based code architecture and dynamically tracks the player's score.

## 🚀 Features

* **Functional Programming Design:** The codebase is cleanly split into modular functions handling specific tasks like user greeting, core quiz logic, result calculations, and replay logic.
* **Case-Insensitive Input Matching:** Automatically standardizes user answers (`.strip().lower()`) so variations in spaces or capitalization won't cause correct answers to be marked wrong.
* **Dynamic Feedback System:** Evaluates the user's final score out of 4 and outputs tailored performance remarks (`Better luck next time!`, `Good job!`, or `Excellent!`).
* **Replay Functionality:** Includes a game-loop system allowing users to instantly restart the quiz to beat their high score without restarting the script.

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Interface:** Command Line Interface (CLI)
